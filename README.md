# Assignment 1: Problem Solving with TypeScript & OOP

## 📌 Assignment Overview
This repository contains my solutions for the **Problem Solving with TypeScript & OOP** assignment from Programming Hero (Level-2). 

The `solutions.ts` file includes 8 different problem-solving tasks. These tasks cover core TypeScript concepts, including:
- Basic types, Optional & Default Parameters
- Type Narrowing (`typeof`)
- Generics & Rest Parameters
- Interfaces & Object manipulations
- Object-Oriented Programming (Classes, Inheritance, Access Modifiers)
- Asynchronous TypeScript (`Promise`)

All code is written cleanly following the strict assignment requirements (no `any` types, explicit parameter/return types, and exact return formats).
